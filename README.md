# otok index

The public index of [otok](https://github.com/otok-dev/otok) recipes: what otok resolves and builds by default.
Browse it in the [catalog](https://otok-dev.github.io/index).

otok reads the index through its HTTPS view, `https://otok-dev.github.io/index`, generated from this repository on
every change; there is nothing to clone. Recipes are added with `otok publish`, which opens a pull request here:
see [CONTRIBUTING.md](CONTRIBUTING.md) for the terms of publication and who may publish.

The data of this repository is dedicated to the public domain under [CC0 1.0](LICENSE). The recipes it names stay
in their own repositories, under their own licenses.
